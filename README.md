# CS-499 ePortfolio

## Overview
This collection of work is from my final computer science project, CS-499. It's a showcase of the skills I've learned in software engineering, designing programs, algorithms, data structures, and working with databases. The projects in this portfolio have been improved and updated to demonstrate my abilities in these areas.

Every project I worked on includes a few key things: the original version, the updated version, some pictures that show how it works and what's new, some documents that explain everything, and a story about what we did and how we did it, from start to finish. We put all this together to show what we've accomplished during the course.

This ePortfolio is meant to show how I've grown technically, how I can solve problems, and how I use computer science ideas in real projects, as well as how I develop software. It's a way to demonstrate my skills and knowledge in a practical way, by sharing the projects I've worked on and what I've learned from them.
