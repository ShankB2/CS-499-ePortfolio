# Original Artifact - CS-340 Database Project

## Overview
This folder contains the original Grazioso Salvare Rescue Dog Dashboard artifact developed in CS-340 before enhancements were implemented.

The original project demonstrates:
- MongoDB database integration
- CRUD operations using Python
- Interactive filtering
- Dashboard visualization using Jupyter Dash
- Geographic mapping using Dash Leaflet

---

## Included Files

### CRUD_Python_Module.py
Original CRUD Python module responsible for MongoDB database communication and CRUD operations.

### ProjectTwoDashboard.ipynb
Original Jupyter Dash dashboard application containing filtering logic, graph generation, table interaction, and geographic mapping functionality.

### Grazioso Salvare Logo.png
Logo image used within the dashboard interface.

---

## Original Project Features
- MongoDB database connectivity
- Interactive rescue filtering
- Dynamic data tables
- Breed visualization graphs
- Geographic map visualization
- Dashboard interaction using Dash callbacks

---

## Limitations of Original Version
The original implementation functioned correctly but contained several areas for improvement including:
- Limited reusable filtering logic
- Query logic embedded directly inside dashboard code
- Limited validation and exception handling
- No aggregation support
- Limited scalability and maintainability
- No indexing optimization

These limitations became the focus of the enhanced version of the project.
